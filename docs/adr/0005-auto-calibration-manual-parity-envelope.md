# ADR 0005：自动校准冻结包络与磁-油门补偿只读参数化

日期：2026-09-14（修订 2026-09-11 方案）
状态：源码实施；本机构建结果见 AUTO_CALIBRATION_PLAN_ZH，板端验收待执行

## 问题

校准请求、差速轮端与看门狗曾使用不同的固定输出限制，弱动力车无法获得入场允许的驱动范围。删除倒退阶段后，运行参数仍索取倒退数据。磁补偿初版直接写参数、只在 RAM 失效，固定值参数又被快照加载器跳过，无法形成跨重启的完整契约。

## 决策

1. 唯一包络 E=入场冻结 MOT_THR_MAX。纵向请求/闭环输出 [0,E]，转向请求 [-1,1]，最终轮端 [-E,E]。退役 RO_CAL_THR_MAX/RO_CAL_TURN_MAX；保留 0.15/s slew、速度/角速度/加速度、围栏和停车守卫。看门狗使用普通归一化/新鲜度规则，校准只收紧为至多 100 ms。
2. 校准纵向不倒退，激励 FWD=0→CW=1→CCW=2，哨兵 3；RTK 经掉头前进返程。无运动时也按时间升档，到 0.995E 后连续 8 s 无运动才报 FAILURE_DRIVE_ENVELOPE。安全链故障按原原因处理。
3. 运行速度和 FF 使用前进响应，转向使用 CW/CCW 一致性。当前模式明确跳过 Manual 共用整形/SLEW，不进入写入事务；skipped_stages 与支持但未完成的 unavailable_stages 分开。PI 只用模型公式，速度/角速度 FF 余量门禁分别 min(0.35,E)/min(0.30,E)，不可行如实未完成，无降级候选。
4. 端点必须是前进顶档、可用样本的后端已应用输出达到 observed_output_max≥0.995E，一次 Info；不增加端点字段，不声称 RPM/电流/扭矩已测量。
5. actuator_output_status 增加后端已应用逻辑轮端和应用时间；共享 32 槽历史选择磁样本之前 100 ms 内的输出。原始磁数据按去/返程分别拟合截距并合并逐轴斜率，避免掉头基线和旧补偿污染；K_body=R*S*K_sensor。
6. 基础磁校正确认并保存后，独立事务提交 CAL_MAG_MOT_KX/KY/KZ/ID/GEN，前端只消费/确认，成功保存后才置 STAGE_MAG_MOT。YAML 的 Firmware Observations 分组正式生成固定值 readOnly、协议拒写和可恢复策略，不维护手写白名单。其他固定产品常量继续跳过快照覆盖。
7. 磁校正及安装角变更在参数写入锁内原子清 ID；各校准事务捕获完整观测组，回滚先恢复校正再恢复观测。GEN 保留最近学习代次，成功递增、溢出拒绝，ID=0 失效；零系数可以是有效结果。
8. 只在两轮均非负的前进工况使用 u=(右+左)/2，磁样本在机体系累计之前应用 B-K*u。原地转向/倒退不套用直线模型。mag_interference_pct=100*norm(K_body)*E/WMM场强，未知 -1、可超过 100%，>30% 提示硬件整改。
9. 基础磁偏置与补偿分别报告；存在磁力计但补偿不可观测或提交失败，整场结果为 PARTIAL。无磁力计仍跳过。不能确认回滚时继续锁存禁 Arm。

## 选择理由与边界

- 使用有符号纵向输出且限定前进学习域；没有转向/反转电流证据，不把绝对输出均值推广到全部工况。
- 只读参数同时承担持久化和 QGC 观测；不另建系数 KV 表，不开放人工写入或降级 PI。
- 参数数量、消息标签及策略集合以正式生成结果为准，不在文档固定目录数量。
- 离线工具解析实际 QGC 导出和最近会话，缺项未知，不自动写入、不猜 PI、不建议缩小停车申报。

## 验收

本轮仅 Linux 原生 dima_rover 构建与工具输入冒烟。QGC 五项只读显示/拒写、重启恢复、同设备新校准后旧补偿持续失效、弱动力起步、真实场地停车和补偿效果均待板端验收。构建通过不能替代车辆证明。

校准开环的纵向请求使用 [0,E] 包络坐标，差速器入口除以 E 转成原有 [0,1] 整形输入，避免 E<1 时重复缩放为 E²；速度 FF、响应剖面及辨识的整形前反馈仍使用差速器标准坐标。闭环 PI 保持标准坐标，纵向输出受 [0,E] 限制；两条路径的最终轮端均受同一冻结包络和末端 slew 约束。

## 状态机闭合修订

响应采集新增正式消息子状态 PROBE/RAMP/SETTLE/COLLECT/BRAKE；从实际可运动下界安排六档平台及一档非零下降，到位后才累计稳定和采样窗口。CW/CCW 使用杆臂转动余量。磁回滚同步计数，内环九段验证后进入 Heading；全局整形/SLEW 明确跳过，使当前适用范围的 SUCCESS 可达。周期日志用 session 和证据快照保持重复终态幂等。实现细节、所有状态和验收记录见 [详细状态机](../AUTO_CALIBRATION_STATE_MACHINE_ZH.md)。
