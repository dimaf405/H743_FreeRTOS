## 八方向基准

下表为等幅端点输入、默认倒车转向规则 RD_REV_STEER=1、ASYM=1、EXPO=0、最大输出=1、等待/渐增已结束时的计算值。S1 为左轮、S3 为右轮；脉宽列使用日志所对应的 REV=1、MIN/CENT/MAX=1100/1500/1900。它是命令基准，不是电气或车辆运动实测。

| 软件杆位 | 右轮命令 | 左轮命令 | S1 左轮 us | S3 右轮 us |
|---|---:|---:|---:|---:|
| 前 F | +1 | +1 | 1100 | 1100 |
| 右前 FR | 0 | +1 | 1100 | 1500 |
| 右 R | -1 | +1 | 1100 | 1900 |
| 右后 BR | 0 | -1 | 1900 | 1500 |
| 后 B | -1 | -1 | 1900 | 1900 |
| 左后 BL | -1 | 0 | 1500 | 1900 |
| 左 L | +1 | -1 | 1900 | 1100 |
| 左前 FL | +1 | 0 | 1500 | 1100 |

等幅右前/右后的公共条件是 S1 左轮前后切换、S3 右轮中立；左前/左后则相反。这个差异可用于区分两路输出和实际中立状态，不能单凭它认定 S1 故障。前进和转向的幅值不相等时，内轮允许反转，不能将表中的零命令推广到所有斜杆位置。

## PWM 后端追加核对

对照 APM SRV_Channel 的中位两侧幅值截断，以及 ChibiOS 的 PWM1、OCxPE 和 N-only 高有效配置，确认本地极性规则一致，但发现并修复了以下缺口：

1. 原频率检查依赖 HAL Init 缓存，漏掉实际模式、预装载、极性/使能和 GPIO AF；现改为运行寄存器核对，时钟计算覆盖 TIMPRE。
2. 原配置异常分支只拉低 GPIO，未完整停止计数器/清比较值；现统一停波并读回状态，坏 Instance 也不妨碍清理固定硬件。
3. 原六路写入只有 UDIS/DMB，没有防止中途被抢占；现使用保存/恢复 PRIMASK 的短临界区并读回 CCR，不在运行中停计数或强制 UG。
4. 原启动先开放 AF 再逐个启动通道；现先在低电平 GPIO 下建立零帧，再开放 AF。
5. 原最终脉宽四舍五入与 APM 相对中位截断不同；现对齐幅值截断，不将不足 1 us 的小命令推离中位。

当前后端没有引脚脉宽捕获，CCR 读回仍是预装载接受证据，timestamp_output 也不是实测边沿。短临界区不能被描述成两定时器硬件原子锁存或示波器结果；尚不能证明这些缺口导致了现场仅右前/右后异常。

内存寄存器模型执行实际 Board C 实现，检查正常 S1/S3 写入、中断屏蔽状态恢复、13 项寄存器/句柄/写入故障、6 个 HAL 启动失败位置、坏配置停波和 TIMPRE 分支，结果通过；模型不模拟真实波形。另有 120006 组归一化 PWM 映射与 APM 方法对照通过。Linux 原生正常构建通过（172.96 s，exit=0，签名镜像 605684 B）。未新增测试文件/框架或测试基础设施，未执行独立 verify 或设备操作。
