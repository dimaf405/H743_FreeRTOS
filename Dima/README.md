# Dima Rover

本目录承载 STM32H743 + FreeRTOS 差速车产品的后续平台适配、中间件、控制模块和产品装配代码。

## 命名规则

- 产品目录统一使用 `Dima`，自有 C++ 命名空间统一使用 `dima`。
- 目录名称不得包含大小写不敏感的 `px4` 字符串。
- 上游源码中的 `px4::`、`PX4_*`、公开 API、参数名、消息名、版权头和许可证文字必须原样保留，不做品牌化替换。

## 阶段 0 边界

- 当前阶段只建立目录职责和移植边界，不导入或编译任何生产源码。
- 不在本目录新增测试框架、测试文件、SITL 或仿真入口。
- 上游代码正式导入前，必须先记录来源版本、原始路径、许可证和本地修改摘要。
